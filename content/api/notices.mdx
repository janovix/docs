# Notices API

**Base path:** `/api/v1/notices`

## Endpoints

| Method   | Path                        | Description                               |
| -------- | --------------------------- | ----------------------------------------- |
| `GET`    | `/notices`                  | List notices                              |
| `GET`    | `/notices/preview`          | Preview operations for a potential notice |
| `GET`    | `/notices/available-months` | Months with reportable operations         |
| `GET`    | `/notices/:id`              | Get notice with summary                   |
| `POST`   | `/notices`                  | Create a notice                           |
| `POST`   | `/notices/:id/generate`     | Generate SAT XML                          |
| `POST`   | `/notices/:id/submit`       | Mark as submitted                         |
| `POST`   | `/notices/:id/acknowledge`  | Record SAT acknowledgment                 |
| `PATCH`  | `/notices/:id`              | Partial update                            |
| `DELETE` | `/notices/:id`              | Delete (draft only)                       |

## Preview a Notice

Before creating a notice, preview which operations would be included:

```
GET /api/v1/notices/preview?year=2025&month=6
```

<Tabs.Tab>
```bash

  -H "Authorization: Bearer YOUR_TOKEN"
```

## Create and Generate a Notice

<Tabs items={['cURL', 'TypeScript', 'Python']}>
<Tabs.Tab>
```bash
# Step 1: Create the notice
NOTICE=$(curl -X POST https://api.janovix.com/api/v1/notices \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"year": 2025, "month": 6}')

NOTICE_ID=$(echo $NOTICE | jq -r '.data.id')

# Step 2: Generate the XML

curl -X POST "https://api.janovix.com/api/v1/notices/$NOTICE_ID/generate" \
 -H "Authorization: Bearer YOUR_TOKEN"

# Step 3: Mark as submitted (after submitting to SAT portal)

curl -X POST "https://api.janovix.com/api/v1/notices/$NOTICE_ID/submit" \
 -H "Authorization: Bearer YOUR_TOKEN" \
 -H "Content-Type: application/json" \
 -d '{"folioNumber": "SAT-2025-06-0001"}'

````
</Tabs.Tab>
<Tabs.Tab>
```typescript
// Step 1: Create
const { data: notice } = await janovixFetch<{ data: Notice }>("/notices", {
  method: "POST",
  body: JSON.stringify({ year: 2025, month: 6 }),
});

// Step 2: Generate XML
await janovixFetch(`/notices/${notice.id}/generate`, { method: "POST" });

// Step 3: Submit to SAT portal manually, then mark
await janovixFetch(`/notices/${notice.id}/submit`, {
  method: "POST",
  body: JSON.stringify({ folioNumber: "SAT-2025-06-0001" }),
});
````

</Tabs.Tab>

# Step 1: Create
notice = session.post(f"{BASE_URL}/notices", json={

}).json()["data"]

session.post(f"{BASE_URL}/notices/{notice['id']}/generate")

# Step 3: Mark as submitted

session.post(f"{BASE_URL}/notices/{notice['id']}/submit", json={
"folioNumber": "SAT-2025-06-0001"
})
