# Dashboard

The **Dashboard** is the **organization home** at `/{orgSlug}` — the first screen after you select an organization. The legacy path `/{orgSlug}/dashboard` **redirects** here.

It gives a real-time snapshot of compliance posture: hero KPIs, optional **report-driven** widgets, **alert** and **client/operation** summaries, and quick navigation into filtered lists.

{/* IMAGE: public/images/aml/dashboard-overview.png - Full dashboard with KPI cards, risk/alert summaries, operation and client stat cards */}

## Hero KPI cards

The top row surfaces key counts with **deep links** into the right module:

| Card                              | Typical focus                                                            |
| --------------------------------- | ------------------------------------------------------------------------ |
| **Total clients**                 | Active clients → opens **Clients**                                       |
| **Transactions today** / activity | Today’s operations → **Operations**                                      |
| **Alerts**                        | Total or active/suspicious-style metric from report summary → **Alerts** |

Exact labels can reflect your **vulnerable activity** (from org settings) for the operations-related card.

## Report-driven widgets

When report summary data is available, the dashboard can show:

### Risk indicators

- **Compliance score** (percentage with progress bar)
- **Critical alerts** count
- **High-risk clients** count
- **Overdue submissions** (e.g. notices or filings past due)

### Alert summary

- Total alerts, **overdue** count, **average resolution** (days)
- **Counts by severity**: `LOW`, `MEDIUM`, `HIGH`, `CRITICAL`  
  Cards link into the alerts list with appropriate context.

## Operation stats

A card summarizing operations for the selected period:

- **Total volume** (formatted in **MXN**)
- **Suspicious transactions** (when applicable)
- **Today’s count** and **total operations**
- Optional **comparison vs last month** (percentage) when comparison data exists

Links go to **Operations** with useful defaults.

## Client stats

- **Total** clients and breakdown: **personas físicas**, **personas morales**, **fideicomisos** (trusts)
- **New clients in period**, **clients with alerts**
- Optional **month-over-month** comparison

Links go to **Clients**.

## UMA and clock

The top bar can show a **UMA** reference badge and your preferred **clock** / timezone (from settings). Threshold math in operations and notices still uses the **UMA for the operation date** stored in the system.

## Time period

The dashboard shows metrics for the **current month** with optional **comparison to the previous month** (percentage changes) when comparison data is available. The period is fixed to the calendar month — there is no date range picker on the dashboard itself.

## Activity vs Dashboard

- **Dashboard** — aggregates, charts, and KPIs at `/{orgSlug}`
- **[Activity Feed](/en/aml/activity)** — full chronological notification list at `/{orgSlug}/activity`

## AI assistant

From the main layout you can open the **AI chat** sidebar to ask questions about workflows and your data (subject to plan limits).

## What to Do First

If you are setting up Janovix for the first time:

1. Go to [Settings → Compliance](/en/settings/compliance) and configure your organization's activity code and RFC
2. Return to the Dashboard — the KPIs will update as you add data
3. Start [registering your clients](/en/aml/clients)
4. Review **[Risk Management](/en/aml/risk)** once clients and operations exist
