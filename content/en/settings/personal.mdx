# Personal Settings

Personal settings apply to your user account across **all organizations** you belong to.

{/* IMAGE: public/images/settings/settings-personal.png - Personal settings page showing avatar upload, name fields, email, timezone selector, theme toggle, and language selector */}

## Profile

| Field            | Description                                                                        |
| ---------------- | ---------------------------------------------------------------------------------- |
| **Avatar**       | Profile photo. Click the avatar circle to upload a new image (JPEG/PNG, max 5 MB). |
| **Display Name** | Your name as shown to other team members and in audit logs.                        |
| **Email**        | Your login email. Contact support to change your email address.                    |

## Preferences

| Setting          | Options                                         | Default |
| ---------------- | ----------------------------------------------- | ------- |
| **Theme**        | Light / Dark / System                           | System  |
| **Language**     | English / Español / Português                   | English |
| **Timezone**     | Any IANA timezone (e.g., `America/Mexico_City`) | `UTC`   |
| **Clock Format** | 12-hour / 24-hour                               | 12-hour |
| **Date format**  | Locale-appropriate patterns                     | Default |

<Callout type="info">
	**Timezone** affects how dates and times are displayed throughout the
	application — reports, operation timestamps, and notice deadlines. Set it to
	your local timezone to avoid confusion.
</Callout>

## Notifications

Configure **in-app notification sound**:

- Turn notification sound on or off
- Choose a **sound preset** and use **Preview** to hear it before saving

These preferences apply to your user session in the Janovix web apps.

## Passkeys (WebAuthn)

For stronger sign-in without SMS, add one or more **passkeys** (platform or security keys):

- **Add** a passkey from a supported browser (Face ID, Touch ID, Windows Hello, or a hardware key)
- **Rename** passkeys to remember which device they belong to
- **Remove** a passkey if you lose a device

Passkeys are optional but recommended after email OTP login.

## Interface

Janovix remembers whether you prefer the sidebar **expanded** or **collapsed**. The choice is **debounced and persisted** server-side so it survives new devices and sessions.

## Security

To sign out from all devices, click **Sign Out Everywhere** at the bottom of the Personal settings page. This invalidates all active sessions for your account.
