# API Integration Guide

The Janovix Public API gives you programmatic access to every AML compliance feature — clients, operations, alerts, watchlist screening, notices, and more. Use it to integrate Janovix into your ERP, CRM, notary management system, or custom workflow.

## Base URL

```
https://api.janovix.com/api/v1
```

All endpoints use HTTPS. The gateway validates your API key, exchanges it for an ephemeral JWT internally, and proxies the request to the AML service — the JWT exchange is invisible to your code.

## API Architecture

```
Your Server
  │
  │  Authorization: Bearer sk_live_...
  ▼
api.janovix.com  (Cloudflare Worker — API gateway)
  │
  ├─ Validates API key → auth-svc (~5-15ms)
  ├─ Receives ephemeral JWT (30-60s expiry, automatic)
  │
  ▼
aml-svc  (internal, via Cloudflare service binding — ~0ms)
  │
  └─ Returns your data
```

<Callout type="info">
	The ephemeral JWT exchange happens automatically inside the gateway. You never
	handle JWTs when using API keys — just include your `sk_live_...` key in every
	request.
</Callout>

## Interactive API Explorer

The interactive Scalar API explorer (auto-generated from OpenAPI) is available at:

```
https://api.janovix.com/docsz
```

The full OpenAPI 3.0 schema is at:

```
https://api.janovix.com/v1/openapi.json
```

Import it into Postman, Insomnia, or any OpenAPI-compatible tool with one click.

## Response Format

All responses follow a consistent envelope:

### Success (list)

```json
{
  "data": [ ... ],
  "pagination": {
    "page": 1,
    "limit": 20,
    "total": 150,
    "totalPages": 8
  }
}
```

### Success (single resource)

```json
{
  "data": { ... }
}
```

### Error

```json
{
  "success": false,
  "error": "NotFound",
  "message": "Client with ID abc123 not found",
  "details": { ... }
}
```

## HTTP Status Codes

| Code  | Meaning                                                   |
| ----- | --------------------------------------------------------- |
| `200` | Success                                                   |
| `201` | Created                                                   |
| `400` | Validation error — check `details` for field-level errors |
| `401` | Unauthorized — missing or invalid API key                 |
| `403` | Forbidden — key revoked, expired, or plan not eligible    |
| `404` | Resource not found                                        |
| `409` | Conflict — duplicate RFC, idempotency key collision, etc. |
| `422` | Unprocessable Entity                                      |
| `429` | Rate limited — check `Retry-After` header                 |
| `502` | AML service temporarily unreachable — retry               |
| `503` | Auth service temporarily unreachable — retry              |

## Rate Limits

Rate limits depend on your subscription plan. When exceeded, the API returns `429 Too Many Requests` with a `Retry-After` header indicating seconds to wait.

| Plan      | Public API access | Requests / minute (when eligible) |
| --------- | ----------------- | --------------------------------- |
| Watchlist | No                | —                                 |
| Business  | No                | —                                 |
| Pro       | Yes               | 300                               |
| Ultra     | Yes               | 1,000                             |

Organizations without API access receive `403` on `api.janovix.com` routes regardless of the table above. See [Authentication](/en/api/authentication).

## Pagination

List endpoints support page-based pagination via query parameters:

| Parameter | Default | Description              |
| --------- | ------- | ------------------------ |
| `page`    | `1`     | Page number (1-indexed)  |
| `limit`   | `20`    | Items per page (max 100) |
