# Catalogs API

Catalogs provide reference data for populating dropdowns and validating inputs across the platform.

**Base path:** `/api/v1/catalogs`

## Available Catalogs

| Catalog Key               | Description                 | Type   |
| ------------------------- | --------------------------- | ------ |
| `countries`               | ISO countries               | Closed |
| `states_mx`               | Mexican states              | Closed |
| `currencies`              | ISO currencies              | Closed |
| `payment_methods`         | Payment method types        | Closed |
| `uma_values`              | Historical UMA values       | Closed |
| `vehicle_brands_land`     | Land vehicle brands         | Open   |
| `vehicle_brands_maritime` | Maritime vehicle brands     | Open   |
| `vehicle_brands_air`      | Air vehicle brands          | Open   |
| `economic_activities`     | SAT economic activity codes | Closed |
| `cfdi_uses`               | CFDI use codes (SAT)        | Closed |
| `cfdi_payment_methods`    | CFDI payment method codes   | Closed |
| `cfdi_payment_forms`      | CFDI payment form codes     | Closed |
| `cfdi_tax_regimes`        | SAT fiscal regimes          | Closed |

**Closed catalogs** contain fixed reference data from the SAT or ISO standards.
**Open catalogs** can have new items added by your organization (e.g., new vehicle brands not in the default list).

## List a Catalog

```
GET /api/v1/catalogs/:catalogKey?search=Toyota&limit=20
```

<Tabs items={['cURL', 'TypeScript', 'Python']}>
<Tabs.Tab>
```bash
# Get all Mexican states
curl "https://api.janovix.com/api/v1/catalogs/states_mx" \
  -H "Authorization: Bearer YOUR_TOKEN"

# Search vehicle brands

curl "https://api.janovix.com/api/v1/catalogs/vehicle_brands_land?search=Toyota" \
 -H "Authorization: Bearer YOUR_TOKEN"

````
</Tabs.Tab>
<Tabs.Tab>
```typescript
// Load a catalog for a form dropdown
async function getCatalog(key: string, search?: string) {
  const params = search ? `?search=${encodeURIComponent(search)}` : "";
  const { data } = await janovixFetch<{ data: CatalogItem[] }>(
    `/catalogs/${key}${params}`
  );
  return data;
}

const states = await getCatalog("states_mx");
const toyotaModels = await getCatalog("vehicle_brands_land", "Toyota");
````

</Tabs.Tab>

## Add a New Item (Open Catalogs Only)

```
POST /api/v1/catalogs/:catalogKey/items
```

<Tabs items={['cURL', 'TypeScript']}>
<Tabs.Tab>
```bash
curl -X POST https://api.janovix.com/api/v1/catalogs/vehicle_brands_land/items \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"key": "RIVIAN", "label": "Rivian"}'
```
</Tabs.Tab>
<Tabs.Tab>
```typescript
await janovixFetch("/catalogs/vehicle_brands_land/items", {
  method: "POST",
  body: JSON.stringify({ key: "RIVIAN", label: "Rivian" }),
});
```
</Tabs.Tab>
</Tabs>

## UMA Values

To get the current active UMA value for threshold calculations:

```
GET /api/v1/uma-values/active
```

```json
{
	"data": {
		"id": "uma_01J...",
		"year": 2026,
		"dailyValue": 117.31,
		"monthlyValue": 3566.22,
		"annualValue": 42794.64,
		"effectiveFrom": "2026-02-01",
		"active": true
	}
}
```

## Exchange Rates

Get the current USD→MXN exchange rate (updated every hour):

```
GET /api/v1/exchange-rates?from=USD&to=MXN
```

```json
{
	"data": {
		"from": "USD",
		"to": "MXN",
		"rate": 17.35,
		"timestamp": "2025-07-16T10:00:00.000Z"
	}
}
```
