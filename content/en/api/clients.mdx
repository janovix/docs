# Clients API

The Clients API manages the registry of clients associated with vulnerable activity operations.

**Base path:** `/api/v1/clients`

## Endpoints

| Method   | Path                      | Description                          |
| -------- | ------------------------- | ------------------------------------ |
| `GET`    | `/clients`                | List clients (paginated, filterable) |
| `GET`    | `/clients/stats`          | Aggregate statistics                 |
| `GET`    | `/clients/:id`            | Get a single client                  |
| `GET`    | `/clients/:id/kyc-status` | Get KYC completion status            |
| `POST`   | `/clients`                | Create a client                      |
| `PUT`    | `/clients/:id`            | Full update                          |
| `PATCH`  | `/clients/:id`            | Partial update                       |
| `DELETE` | `/clients/:id`            | Soft delete                          |

  uri = URI("#{BASE_URL}#{path}")
  req = Net::HTTP::Post.new(uri)

  req["Content-Type"]  = "application/json"

function janovixPost(string $path, array $body): array {
    global $baseUrl, $apiKey;
    $ch = curl_init("{$baseUrl}{$path}");
    curl_setopt_array($ch, [
        CURLOPT_RETURNTRANSFER => true,
        CURLOPT_POST           => true,
        CURLOPT_POSTFIELDS     => json_encode($body),
        CURLOPT_HTTPHEADER     => [
            "Authorization: Bearer {$apiKey}",
            "Content-Type: application/json",
        ],
    ]);
    $response = curl_exec($ch);
    curl_close($ch);
    return json_decode($response, true);
}

## List Clients

```
GET /api/v1/clients?page=1&limit=20&kycStatus=INCOMPLETE
```

### Query Parameters

| Parameter        | Type    | Description                               |
| ---------------- | ------- | ----------------------------------------- |
| `page`           | number  | Page number (default: 1)                  |
| `limit`          | number  | Items per page (max 100, default: 20)     |
| `search`         | string  | Search by name or RFC                     |
| `kycStatus`      | string  | Filter by KYC status                      |
| `personType`     | string  | Filter by `PHYSICAL`, `MORAL`, or `TRUST` |
| `isPEP`          | boolean | Filter PEP clients                        |
| `ofacSanctioned` | boolean | Filter OFAC-sanctioned clients            |

## Get KYC Status

```
GET /api/v1/clients/:id/kyc-status
```

Returns a detailed KYC completion breakdown including which sections are complete, pending, or missing:

```json
{
	"data": {
		"status": "INCOMPLETE",
		"completionPercentage": 45,
		"sections": {
			"personalInfo": "complete",
			"documents": "incomplete",
			"address": "complete",
			"shareholders": "not_applicable",
			"beneficialControllers": "not_applicable"
		},
		"missingFields": ["identityDocument", "taxDocument"]
	}
}
```
