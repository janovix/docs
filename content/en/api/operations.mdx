# Operations API

The Operations API handles the recording and management of vulnerable activity transactions.

**Base path:** `/api/v1/operations`

## Endpoints

| Method   | Path                                       | Description                                |
| -------- | ------------------------------------------ | ------------------------------------------ |
| `GET`    | `/operations`                              | List operations                            |
| `GET`    | `/operations/activities`                   | List all 20 activity types with thresholds |
| `GET`    | `/operations/activities/:code/fields`      | Get field metadata for an activity         |
| `GET`    | `/operations/thresholds`                   | UMA thresholds for all activities          |
| `GET`    | `/operations/:id`                          | Get an operation                           |
| `POST`   | `/operations`                              | Create an operation                        |
| `POST`   | `/operations/bulk-import`                  | Bulk create (max 100)                      |
| `PUT`    | `/operations/:id`                          | Full update                                |
| `DELETE` | `/operations/:id`                          | Soft delete                                |
| `GET`    | `/operations/client/:clientId/accumulated` | Client's 6-month accumulated totals        |

    "alertsGenerated": 1,

<Callout type="info">
	The `umaEquivalent` and `isAboveNoticeThreshold` fields are calculated
	automatically. `alertsGenerated` indicates how many alert rules fired for this
	operation.
</Callout>

## Get Activity Fields

Before creating an operation, use this endpoint to get the required and optional fields for a specific activity:

```
GET /api/v1/operations/activities/VEH/fields
```

```json
{
	"data": {
		"activityCode": "VEH",
		"name": "Comercialización o distribución de vehículos",
		"extensionFields": [
			{
				"name": "vehicleType",
				"required": true,
				"type": "enum",
				"options": ["TERRESTRIAL", "MARITIME", "AIR"]
			},
			{ "name": "brand", "required": true, "type": "string" },
			{ "name": "model", "required": true, "type": "string" },
			{ "name": "year", "required": true, "type": "integer" },
			{ "name": "vin", "required": false, "type": "string" },
			{ "name": "isNew", "required": true, "type": "boolean" }
		]
	}
}
```

## Bulk Import

```
POST /api/v1/operations/bulk-import
```

```json
{
  "operations": [
    { "clientId": "...", "activityCode": "VEH", "amount": 850000, ... },
    { "clientId": "...", "activityCode": "INM", "amount": 3500000, ... }
  ]
}
```

Maximum 100 operations per batch. Returns per-item success/error results.
