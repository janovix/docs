# Realizar una Búsqueda

{/* IMAGE: public/images/watchlist/watchlist-search.png - Search interface showing name input field, dataset filter checkboxes (OFAC/UNSC/SAT69B/PEP/Adverse Media), and entity type selector */}

## Búsqueda básica

<Steps>
### Elige persona física vs moral

Usa el interruptor de **tipo de entidad** para que el formulario pida la **fecha** correcta: nacimiento (persona) o constitución (empresa).

### Ingresa un nombre

Escribe el nombre completo o razón social. El producto normaliza el texto (p. ej. mayúsculas). La interfaz exige más de **3 caracteres** antes de enviar para evitar ruido.

Para mejores resultados:

- Nombre legal completo según documentos
- Personas físicas: `APELLIDO PATERNO APELLIDO MATERNO Nombre(s)`
- Empresas: razón social completa

### Opciones avanzadas (opcional)

Abre **Avanzado** para afinar:

- **Identificadores** — separados por comas (pasaporte, RFC, etc.)
- **Países** — multiselección de nacionalidad / jurisdicción
- **Fechas** — nacimiento o constitución según el tipo de entidad

En la pantalla principal el umbral de similitud está **fijo en 0,875** — no se ajusta por búsqueda desde el formulario principal.

### Conjuntos de datos (opcional)

Por defecto se consultan todos. Desmarca los que no necesites:

- OFAC SDN, UNSC, SAT 69-B, PEP, medios adversos

La disponibilidad de PEP / medios adversos también puede depender de **banderas de función** de la organización.

### Ejecutar

Pulsa **Search** o Enter. Primero llegan OFAC/UNSC/SAT 69-B; **PEP** y **medios adversos** pueden completarse después vía **SSE** en la ruta de resultados.

</Steps>

## Recorrido inicial

En la primera visita, un **tour guiado** (driver.js) resalta el selector de entidad, el campo de búsqueda, avanzado y enviar. Al cerrarlo, el estado queda en **localStorage**.

## Búsquedas recientes

La portada muestra las **últimas cinco** consultas para reabrirlas rápido.

## Handoff de sesión

Tras enviar, la app guarda estado ligero en **sessionStorage** para que la página de **detalle de consulta** pinte al instante mientras termina la petición de red.

## Búsqueda por Identificador

Para una coincidencia de mayor confianza, busca por un identificador específico en lugar de un nombre:

| Tipo de Identificador | Ejemplo                     |
| --------------------- | --------------------------- |
| Pasaporte             | `A1234567`                  |
| RFC (México)          | `XAXX010101000`             |
| NIT (Colombia)        | `900123456`                 |
| ID OFAC               | Identificador numérico OFAC |

Las búsquedas por identificador realizan **coincidencia exacta** y devuelven resultados de inmediato.

## Interpretación de Resultados

{/* IMAGE: public/images/watchlist/watchlist-results.png - Search results page showing match cards with entity name, database badge, match score percentage, and brief details */}

Cada resultado de búsqueda muestra:

| Campo                       | Descripción                                                                            |
| --------------------------- | -------------------------------------------------------------------------------------- |
| **Puntaje de Coincidencia** | Puntaje general de confianza (0–100%)                                                  |
| **Base de datos**           | De qué lista proviene la coincidencia (OFAC SDN, UNSC, SAT 69-B, PEP, Medios Adversos) |
| **Nombre de la entidad**    | El nombre en la lista                                                                  |
| **Tipo de entidad**         | Persona física u organización                                                          |
| **País**                    | Nacionalidad o país de registro                                                        |
| **Estado**                  | Sanción activa, estado de designación o fase del SAT 69-B                              |

### Desglose del Puntaje

{/* IMAGE: public/images/watchlist/watchlist-result-detail.png - Expanded result card showing score breakdown: vector score, name similarity score, metadata score, identifier match indicator */}

Expande cualquier resultado para ver los **componentes del puntaje**:

| Componente del Puntaje            | Lo que Mide                                                                                |
| --------------------------------- | ------------------------------------------------------------------------------------------ |
| **Puntaje de nombre**             | Similitud de nombre Jaro-Winkler entre la consulta y el nombre coincidente                 |
| **Puntaje vectorial**             | Similitud semántica (Cloudflare Vectorize + embeddings de IA)                              |
| **Puntaje de metadatos**          | Calidad de coincidencia en campos adicionales (país, nacionalidad, fecha de nacimiento)    |
| **Coincidencia de identificador** | Booleano — coincidencia exacta de identificador encontrada (anula los umbrales de puntaje) |

### Interpretación del Puntaje

| Rango de Puntaje | Recomendación                                                                    |
| ---------------- | -------------------------------------------------------------------------------- |
| 90–100%          | Coincidencia de alta confianza — requiere revisión inmediata                     |
| 70–89%           | Coincidencia probable — revisa los detalles antes de continuar                   |
| 50–69%           | Posible coincidencia — puede ser una coincidencia de nombre; revisa el contexto  |
| < 50%            | Baja confianza — probablemente no es la misma persona, pero registra la revisión |

<Callout type="error">
	**Nunca procedas con una transacción si hay una coincidencia del 90% o más sin
	una revisión documentada.** Aunque determines que es un falso positivo, la
	decisión y la justificación deben quedar registradas. El historial de
	consultas en Janovix sirve como este registro.
</Callout>

## Resultados Asíncronos (PEP y Medios Adversos)

Las búsquedas de PEP y Medios Adversos se ejecutan en contenedores con inteligencia artificial y pueden tardar entre 10 y 60 segundos en devolver resultados. Mientras se procesan:

- Aparece un indicador de carga junto a las secciones de PEP y Medios Adversos
- Los resultados se transmiten mediante Server-Sent Events conforme van llegando
- Puedes salir de la página — los resultados se guardan en tu [Historial de Consultas](/es/watchlist/query-history) y estarán disponibles cuando regreses

## Cómo Actuar ante una Coincidencia

Cuando se encuentra una coincidencia:

1. **Revisa los detalles completos de la entidad** — alias, fechas, identificadores, domicilio, motivo de inclusión en la lista
2. **Determina si es la misma persona/entidad** que tu cliente (los falsos positivos son comunes con nombres muy frecuentes)
3. **Documenta tu conclusión** en tus notas internas de cumplimiento
4. Si se confirma: no procedas con la transacción; escala de acuerdo con tu política interna de PLD
5. Si es un falso positivo: regístralo en las notas de tu consulta para el rastro de auditoría
