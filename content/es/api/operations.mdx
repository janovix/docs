# API de Operaciones

La API de Operaciones maneja el registro y la gestión de transacciones de actividades vulnerables.

**Ruta base:** `/api/v1/operations`

## Endpoints

| Método   | Ruta                                       | Descripción                                       |
| -------- | ------------------------------------------ | ------------------------------------------------- |
| `GET`    | `/operations`                              | Listar operaciones                                |
| `GET`    | `/operations/activities`                   | Listar los 20 tipos de actividad con sus umbrales |
| `GET`    | `/operations/activities/:code/fields`      | Obtener metadatos de campos para una actividad    |
| `GET`    | `/operations/thresholds`                   | Umbrales UMA para todas las actividades           |
| `GET`    | `/operations/:id`                          | Obtener una operación                             |
| `POST`   | `/operations`                              | Crear una operación                               |
| `POST`   | `/operations/bulk-import`                  | Creación masiva (máx. 100)                        |
| `PUT`    | `/operations/:id`                          | Actualización completa                            |
| `DELETE` | `/operations/:id`                          | Eliminación lógica                                |
| `GET`    | `/operations/client/:clientId/accumulated` | Totales acumulados del cliente en 6 meses         |


<Callout type="info">
	Los campos `umaEquivalent` e `isAboveNoticeThreshold` se calculan
	automáticamente. `alertsGenerated` indica cuántas reglas de alerta se
	activaron para esta operación.
</Callout>

## Obtener Campos de Actividad

Antes de crear una operación, usa este endpoint para obtener los campos requeridos y opcionales de una actividad específica:

```
GET /api/v1/operations/activities/VEH/fields
```

```json
{
	"data": {
		"activityCode": "VEH",
		"name": "Comercialización o distribución de vehículos",
		"extensionFields": [
			{
				"name": "vehicleType",
				"required": true,
				"type": "enum",
				"options": ["TERRESTRIAL", "MARITIME", "AIR"]
			},
			{ "name": "brand", "required": true, "type": "string" },
			{ "name": "model", "required": true, "type": "string" },
			{ "name": "year", "required": true, "type": "integer" },
			{ "name": "vin", "required": false, "type": "string" },
			{ "name": "isNew", "required": true, "type": "boolean" }
		]
	}
}
```

## Importación Masiva

```
POST /api/v1/operations/bulk-import
```

```json
{
  "operations": [
    { "clientId": "...", "activityCode": "VEH", "amount": 850000, ... },
    { "clientId": "...", "activityCode": "INM", "amount": 3500000, ... }
  ]
}
```

Máximo 100 operaciones por lote. Devuelve resultados de éxito/error por elemento.
