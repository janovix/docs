# API de Avisos

**Ruta base:** `/api/v1/notices`

## Endpoints

| Método   | Ruta                        | Descripción                                         |
| -------- | --------------------------- | --------------------------------------------------- |
| `GET`    | `/notices`                  | Listar avisos                                       |
| `GET`    | `/notices/preview`          | Vista previa de operaciones para un aviso potencial |
| `GET`    | `/notices/available-months` | Meses con operaciones reportables                   |
| `GET`    | `/notices/:id`              | Obtener aviso con resumen                           |
| `POST`   | `/notices`                  | Crear un aviso                                      |
| `POST`   | `/notices/:id/generate`     | Generar XML para el SAT                             |
| `POST`   | `/notices/:id/submit`       | Marcar como enviado                                 |
| `POST`   | `/notices/:id/acknowledge`  | Registrar acuse del SAT                             |
| `PATCH`  | `/notices/:id`              | Actualización parcial                               |
| `DELETE` | `/notices/:id`              | Eliminar (solo borradores)                          |

## Vista Previa de un Aviso

Antes de crear un aviso, obtén una vista previa de las operaciones que se incluirían:

```
GET /api/v1/notices/preview?year=2025&month=6
```

<Tabs items={['cURL', 'TypeScript', 'Python']}>
<Tabs.Tab>
```bash
curl "https://api.janovix.com/api/v1/notices/preview?year=2025&month=6" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</Tabs.Tab>
<Tabs.Tab>
```typescript

  "/notices/preview?year=2025&month=6"

console.log(`${preview.operationCount} operaciones por un total de ${preview.totalAmount} MXN`);
```
</Tabs.Tab>

## Crear y Generar un Aviso

<Tabs items={['cURL', 'TypeScript', 'Python']}>
<Tabs.Tab>
```bash
# Paso 1: Crear el aviso
NOTICE=$(curl -X POST https://api.janovix.com/api/v1/notices \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"year": 2025, "month": 6}')

NOTICE_ID=$(echo $NOTICE | jq -r '.data.id')

# Paso 2: Generar el XML

curl -X POST "https://api.janovix.com/api/v1/notices/$NOTICE_ID/generate" \
 -H "Authorization: Bearer YOUR_TOKEN"

# Paso 3: Marcar como enviado (después de enviarlo al portal del SAT)

curl -X POST "https://api.janovix.com/api/v1/notices/$NOTICE_ID/submit" \
 -H "Authorization: Bearer YOUR_TOKEN" \
 -H "Content-Type: application/json" \
 -d '{"folioNumber": "SAT-2025-06-0001"}'

````
</Tabs.Tab>
<Tabs.Tab>
```typescript
// Paso 1: Crear
const { data: notice } = await janovixFetch<{ data: Notice }>("/notices", {
  method: "POST",
  body: JSON.stringify({ year: 2025, month: 6 }),
});

// Paso 2: Generar XML
await janovixFetch(`/notices/${notice.id}/generate`, { method: "POST" });

// Paso 3: Enviar manualmente al portal del SAT, luego marcar
await janovixFetch(`/notices/${notice.id}/submit`, {
  method: "POST",
  body: JSON.stringify({ folioNumber: "SAT-2025-06-0001" }),
});
````

session.post(f"{BASE_URL}/notices/{notice['id']}/submit", json={
"folioNumber": "SAT-2025-06-0001"
})
