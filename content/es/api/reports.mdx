# API de Reportes

**Ruta base:** `/api/v1/reports`

## Endpoints

| Método   | Ruta                         | Descripción                              |
| -------- | ---------------------------- | ---------------------------------------- |
| `GET`    | `/reports/templates`         | Listar plantillas de reporte disponibles |
| `GET`    | `/reports`                   | Listar reportes                          |
| `GET`    | `/reports/preview`           | Vista previa de datos del reporte        |
| `GET`    | `/reports/aggregate/summary` | Agregación de resumen ejecutivo          |
| `GET`    | `/reports/aggregate/alerts`  | Agregación de métricas de alertas        |
| `GET`    | `/reports/:id`               | Obtener un reporte                       |
| `POST`   | `/reports`                   | Crear un reporte                         |
| `POST`   | `/reports/:id/generate`      | Generar el reporte (compilar a PDF)      |
| `PATCH`  | `/reports/:id`               | Actualización parcial                    |
| `DELETE` | `/reports/:id`               | Eliminar (solo borradores)               |

## Obtener Resumen Agregado

Para integraciones con dashboards, usa el endpoint agregado directamente sin crear un reporte formal:

<Tabs items={['cURL', 'TypeScript', 'Python']}>
<Tabs.Tab>
```bash
curl "https://api.janovix.com/api/v1/reports/aggregate/summary?dateFrom=2025-01-01&dateTo=2025-06-30" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</Tabs.Tab>
<Tabs.Tab>
```typescript
const summary = await janovixFetch<AggregateSummary>(
  "/reports/aggregate/summary?dateFrom=2025-01-01&dateTo=2025-06-30"
);
console.log(`Clientes: ${summary.totalClients}, Alertas: ${summary.totalAlerts}`);
```
</Tabs.Tab>
<Tabs.Tab>
```python
summary = session.get(f"{BASE_URL}/reports/aggregate/summary", params={
    "dateFrom": "2025-01-01",
    "dateTo": "2025-06-30",
}).json()["data"]
```
</Tabs.Tab>
</Tabs>

## Crear y Generar un Reporte

<Tabs items={['cURL', 'TypeScript', 'Python']}>
<Tabs.Tab>
```bash
# Paso 1: Crear el reporte
REPORT=$(curl -X POST https://api.janovix.com/api/v1/reports \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "template": "EXECUTIVE_SUMMARY",
    "title": "Q2 2025 Compliance Report",
    "dateFrom": "2025-04-01",
    "dateTo": "2025-06-30"
  }')

REPORT_ID=$(echo $REPORT | jq -r '.data.id')

# Paso 2: Generar

curl -X POST "https://api.janovix.com/api/v1/reports/$REPORT_ID/generate" \
 -H "Authorization: Bearer YOUR_TOKEN"

````
</Tabs.Tab>
<Tabs.Tab>
```typescript
const { data: report } = await janovixFetch<{ data: Report }>("/reports", {
  method: "POST",
  body: JSON.stringify({
    template: "EXECUTIVE_SUMMARY",
    title: "Q2 2025 Compliance Report",
    dateFrom: "2025-04-01",
    dateTo: "2025-06-30",
  }),
});

await janovixFetch(`/reports/${report.id}/generate`, { method: "POST" });
````

</Tabs.Tab>
<Tabs.Tab>
```python
report = session.post(f"{BASE_URL}/reports", json={
    "template": "EXECUTIVE_SUMMARY",
    "title": "Q2 2025 Compliance Report",
    "dateFrom": "2025-04-01",
    "dateTo": "2025-06-30",
}).json()["data"]

session.post(f"{BASE_URL}/reports/{report['id']}/generate")

```
</Tabs.Tab>
