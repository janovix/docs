# API de Alertas

**Ruta base:** `/api/v1/alerts`

## Endpoints

| Método   | Ruta                 | Descripción             |
| -------- | -------------------- | ----------------------- |
| `GET`    | `/alerts`            | Listar alertas          |
| `GET`    | `/alerts/:id`        | Obtener una alerta      |
| `POST`   | `/alerts`            | Crear una alerta manual |
| `PUT`    | `/alerts/:id`        | Actualización completa  |
| `PATCH`  | `/alerts/:id`        | Actualización parcial   |
| `POST`   | `/alerts/:id/cancel` | Cancelar una alerta     |
| `DELETE` | `/alerts/:id`        | Eliminar una alerta     |

## Listar Alertas

```
GET /api/v1/alerts?status=DETECTED&severity=HIGH&page=1&limit=20
```

### Parámetros de Consulta

| Parámetro             | Descripción                                                       |
| --------------------- | ----------------------------------------------------------------- |
| `status`              | `DETECTED`, `FILE_GENERATED`, `SUBMITTED`, `OVERDUE`, `CANCELLED` |
| `severity`            | `LOW`, `MEDIUM`, `HIGH`, `CRITICAL`                               |
| `clientId`            | Filtrar alertas de un cliente específico                          |
| `activityCode`        | Filtrar por tipo de actividad                                     |
| `dateFrom` / `dateTo` | Filtro por rango de fechas                                        |

## Crear una Alerta Manual

```
POST /api/v1/alerts
```

<Tabs items={['cURL', 'TypeScript', 'Python']}>
<Tabs.Tab>
```bash
curl -X POST https://api.janovix.com/api/v1/alerts \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "clientId": "clnt_01J...",
    "operationId": "op_01J...",
    "severity": "HIGH",
    "reason": "Client reported unusual transaction pattern inconsistent with stated business",
    "idempotencyKey": "manual-alert-2025-07-16-001"
  }'
```
</Tabs.Tab>
<Tabs.Tab>
```typescript
const alert = await janovixFetch<{ data: Alert }>("/alerts", {
  method: "POST",
  body: JSON.stringify({
    clientId: "clnt_01J...",
    operationId: "op_01J...",
    severity: "HIGH",
    reason: "Unusual pattern detected",
    idempotencyKey: `manual-${Date.now()}`,
  }),
});
```
</Tabs.Tab>
<Tabs.Tab>
```python
import uuid

alert = session.post(f"{BASE_URL}/alerts", json={
"clientId": "clnt_01J...",
"operationId": "op_01J...",
"severity": "HIGH",
"reason": "Unusual pattern detected",
"idempotencyKey": str(uuid.uuid4()),
}).json()["data"]

```

## Cancelar una Alerta

```

POST /api/v1/alerts/:id/cancel

````

<Tabs items={['cURL', 'TypeScript', 'Python']}>
<Tabs.Tab>
```bash
curl -X POST https://api.janovix.com/api/v1/alerts/alrt_01J.../cancel \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"reason": "Verified as legitimate transaction — client provided documentation"}'
````
