# Guía de Integración API

La API Pública de Janovix te brinda acceso programático a todas las funciones de cumplimiento AML — clientes, operaciones, alertas, verificación en listas de vigilancia, avisos y más. Úsala para integrar Janovix en tu ERP, CRM, sistema de gestión notarial o flujo de trabajo personalizado.

## URL Base

```
https://api.janovix.com/api/v1
```

Todos los endpoints utilizan HTTPS. El gateway valida tu llave de API, la intercambia por un JWT efímero de forma interna, y reenvía la solicitud al servicio AML — el intercambio de JWT es invisible para tu código.

## Arquitectura de la API

```
Tu Servidor
  │
  │  Authorization: Bearer sk_live_...
  ▼
api.janovix.com  (Cloudflare Worker — gateway API)
  │
  ├─ Valida llave de API → auth-svc (~5-15ms)
  ├─ Recibe JWT efímero (expiración 30-60s, automático)
  │
  ▼
aml-svc  (interno, vía Cloudflare service binding — ~0ms)
  │
  └─ Devuelve tus datos
```

<Callout type="info">
	El intercambio de JWT efímero ocurre automáticamente dentro del gateway. Nunca
	gestionas JWTs al usar llaves de API — solo incluye tu llave `sk_live_...` en
	cada solicitud.
</Callout>

## Explorador Interactivo de API

El explorador interactivo Scalar (generado automáticamente desde OpenAPI) está disponible en:

```
https://api.janovix.com/docsz
```

El esquema completo OpenAPI 3.0 se encuentra en:

```
https://api.janovix.com/v1/openapi.json
```

Impórtalo en Postman, Insomnia o cualquier herramienta compatible con OpenAPI con un solo clic.

## Formato de Respuesta

Todas las respuestas siguen un sobre consistente:

### Éxito (lista)

```json
{
  "data": [ ... ],
  "pagination": {
    "page": 1,
    "limit": 20,
    "total": 150,
    "totalPages": 8
  }
}
```

### Éxito (recurso individual)

```json
{
  "data": { ... }
}
```

### Error

```json
{
  "success": false,
  "error": "NotFound",
  "message": "Client with ID abc123 not found",
  "details": { ... }
}
```

## Códigos de Estado HTTP

| Código | Significado                                                        |
| ------ | ------------------------------------------------------------------ |
| `200`  | Éxito                                                              |
| `201`  | Creado                                                             |
| `400`  | Error de validación — revisa `details` para errores por campo      |
| `401`  | No autorizado — llave de API ausente o inválida                    |
| `403`  | Prohibido — llave revocada, expirada o plan no elegible            |
| `404`  | Recurso no encontrado                                              |
| `409`  | Conflicto — RFC duplicado, colisión de llave de idempotencia, etc. |
| `422`  | Entidad no procesable                                              |
| `429`  | Límite de velocidad alcanzado — revisa el encabezado `Retry-After` |
| `502`  | Servicio AML temporalmente no disponible — reintenta               |
| `503`  | Servicio de autenticación temporalmente no disponible — reintenta  |

## Límites de Velocidad

Los límites de velocidad dependen de tu plan de suscripción. Al superarlos, la API devuelve `429 Too Many Requests` con un encabezado `Retry-After` que indica los segundos de espera.

| Plan     | Solicitudes / minuto |
| -------- | -------------------- |
| Business | 60                   |
| Pro      | 300                  |
| Ultra    | 1,000                |

## Paginación

Los endpoints de listado admiten paginación basada en páginas mediante parámetros de consulta:

| Parámetro | Predeterminado | Descripción                       |
| --------- | -------------- | --------------------------------- |
| `page`    | `1`            | Número de página (índice desde 1) |
| `limit`   | `20`           | Elementos por página (máx. 100)   |
