# API de Catálogos

Los catálogos proporcionan datos de referencia para poblar listas desplegables y validar entradas en toda la plataforma.

**Ruta base:** `/api/v1/catalogs`

## Catálogos Disponibles

| Clave del Catálogo        | Descripción                        | Tipo    |
| ------------------------- | ---------------------------------- | ------- |
| `countries`               | Países ISO                         | Cerrado |
| `states_mx`               | Estados de México                  | Cerrado |
| `currencies`              | Divisas ISO                        | Cerrado |
| `payment_methods`         | Tipos de métodos de pago           | Cerrado |
| `uma_values`              | Valores históricos de UMA          | Cerrado |
| `vehicle_brands_land`     | Marcas de vehículos terrestres     | Abierto |
| `vehicle_brands_maritime` | Marcas de vehículos marítimos      | Abierto |
| `vehicle_brands_air`      | Marcas de vehículos aéreos         | Abierto |
| `economic_activities`     | Códigos de actividad económica SAT | Cerrado |
| `cfdi_uses`               | Códigos de uso de CFDI (SAT)       | Cerrado |
| `cfdi_payment_methods`    | Códigos de método de pago CFDI     | Cerrado |
| `cfdi_payment_forms`      | Códigos de forma de pago CFDI      | Cerrado |
| `cfdi_tax_regimes`        | Regímenes fiscales SAT             | Cerrado |

Los **catálogos cerrados** contienen datos de referencia fijos del SAT o de estándares ISO.
Los **catálogos abiertos** permiten agregar nuevos elementos por tu organización (por ejemplo, nuevas marcas de vehículos que no estén en la lista predeterminada).

## Consultar un Catálogo

```
GET /api/v1/catalogs/:catalogKey?search=Toyota&limit=20
```

<Tabs items={['cURL', 'TypeScript', 'Python']}>
<Tabs.Tab>
```bash
# Obtener todos los estados de México
curl "https://api.janovix.com/api/v1/catalogs/states_mx" \
  -H "Authorization: Bearer YOUR_TOKEN"

# Buscar marcas de vehículos

curl "https://api.janovix.com/api/v1/catalogs/vehicle_brands_land?search=Toyota" \
 -H "Authorization: Bearer YOUR_TOKEN"

````
</Tabs.Tab>
<Tabs.Tab>
```typescript
// Cargar un catálogo para un desplegable de formulario
async function getCatalog(key: string, search?: string) {
  const params = search ? `?search=${encodeURIComponent(search)}` : "";
  const { data } = await janovixFetch<{ data: CatalogItem[] }>(
    `/catalogs/${key}${params}`
  );
  return data;
}

const states = await getCatalog("states_mx");
const toyotaModels = await getCatalog("vehicle_brands_land", "Toyota");
````

</Tabs.Tab>
<Tabs.Tab>
```python
def get_catalog(key: str, search: str = None) -> list:
    params = {"search": search} if search else {}
    return session.get(
        f"{BASE_URL}/catalogs/{key}", params=params
    ).json()["data"]

states = get_catalog("states_mx")
brands = get_catalog("vehicle_brands_land", search="Toyota")

````
</Tabs.Tab>
</Tabs>

## Agregar un Nuevo Elemento (Solo Catálogos Abiertos)

```
POST /api/v1/catalogs/:catalogKey/items
```

<Tabs items={['cURL', 'TypeScript']}>
<Tabs.Tab>
```bash
curl -X POST https://api.janovix.com/api/v1/catalogs/vehicle_brands_land/items \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"key": "RIVIAN", "label": "Rivian"}'
```
</Tabs.Tab>
<Tabs.Tab>
```typescript
await janovixFetch("/catalogs/vehicle_brands_land/items", {
  method: "POST",
  body: JSON.stringify({ key: "RIVIAN", label: "Rivian" }),
});
```
</Tabs.Tab>
</Tabs>

## Valores de UMA

Para obtener el valor de UMA activo actual para cálculos de umbrales:

```
GET /api/v1/uma-values/active
```

```json
{
	"data": {
		"id": "uma_01J...",
		"year": 2025,
		"dailyValue": 113.14,
		"monthlyValue": 3439.76,
		"annualValue": 41286.12,
		"effectiveFrom": "2025-02-01",
		"active": true
	}
}
```

## Tipos de Cambio

Obtén el tipo de cambio actual USD→MXN (actualizado cada hora):

```
GET /api/v1/exchange-rates?from=USD&to=MXN
```

```json
{
	"data": {
		"from": "USD",
		"to": "MXN",
		"rate": 17.35,
		"timestamp": "2025-07-16T10:00:00.000Z"
	}
}
```
