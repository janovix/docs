# Operaciones

Las **Operaciones** son las transacciones individuales que registras por cada actividad vulnerable que llevas a cabo. Son el insumo principal para la detección de alertas y la generación de avisos ante el SAT.

{/* IMAGE: public/images/aml/operation-list.png - Operations list showing activity type column, client name, amount, UMA equivalent, and status */}

## ¿Qué es una Operación de Actividad Vulnerable?

Una operación es cualquier acto, transacción o servicio realizado en el contexto de una de las 20 actividades listadas en el Art. 17 de la LFPIORPI. Janovix soporta los 20 tipos de actividad con campos de datos específicos por actividad.

## Tipos de Actividad Compatibles

| Código | Actividad                            | Umbral de Aviso (aprox. MXN 2026)            |
| ------ | ------------------------------------ | -------------------------------------------- |
| `JYS`  | Juegos y Sorteos (Gambling)          | ≥ 645 × $117.31 = ~$75,665                   |
| `TSC`  | Tarjetas de Servicios/Crédito        | ≥ 1,285 UMAs/mes                             |
| `TPP`  | Tarjetas Prepagadas                  | ≥ 645 UMAs                                   |
| `CHV`  | Cheques de Viajero                   | ≥ 645 UMAs                                   |
| `MPC`  | Mutuo/Préstamo/Crédito               | ≥ 1,605 UMAs                                 |
| `INM`  | Inmuebles (Real Estate)              | ≥ 8,025 UMAs                                 |
| `DIN`  | Desarrollo Inmobiliario              | ≥ 8,025 UMAs                                 |
| `MJR`  | Metales/Joyas/Relojes                | ≥ 1,605 UMAs                                 |
| `OBA`  | Obras de Arte y Antigüedades         | ≥ 4,815 UMAs                                 |
| `VEH`  | Vehículos (terrestre/aéreo/marítimo) | ≥ 6,420 UMAs                                 |
| `BLI`  | Blindaje (Armoring)                  | ≥ 4,815 UMAs                                 |

## Registrar una Nueva Operación

{/* IMAGE: public/images/aml/operation-create.png - Operation creation form showing activity selector, client selector, amount, and date fields */}

<Steps>
### Seleccionar el Tipo de Actividad
Navega a **Operaciones** y haz clic en **+ Nueva Operación**. Selecciona el código de actividad que corresponde a tu transacción (p. ej., `VEH` para una venta de vehículo).

### Vincular a un Cliente

Busca y selecciona el cliente asociado a esta transacción. El cliente debe estar registrado; si no lo está, [regístralo primero](/es/aml/clients).

### Ingresar los Datos Principales de la Transacción

- **Fecha de operación** — La fecha en que ocurrió la transacción (no la fecha de registro)
- **Monto** — Monto de la transacción
- **Moneda** — MXN o moneda extranjera (se convierte automáticamente usando el tipo de cambio del día)
- **Equivalente en UMA** — Calculado automáticamente con base en el valor UMA de la fecha de operación

### Completar los Campos Específicos de la Actividad

Cada tipo de actividad tiene campos adicionales obligatorios:

{/* IMAGE: public/images/aml/operation-activity-fields.png - Vehicle activity fields showing brand, model, year, VIN, type (land/air/marine) */}

**Ejemplo — Vehículos (`VEH`):**

- Tipo de vehículo (terrestre / marítimo / aéreo)
- Marca, modelo, año
- NIV o número de serie
- Nuevo o usado

**Ejemplo — Inmuebles (`INM`):**

- Tipo de inmueble (casa, departamento, comercial, terreno)
- Valor catastral
- Valor comercial
- Municipio y estado

### Agregar Formas de Pago

{/* IMAGE: public/images/aml/operation-payment-methods.png - Payment methods section showing method type, amount, and currency for each payment */}

Las operaciones pueden tener múltiples formas de pago. Agrega cada pago con:

- Tipo de forma de pago (efectivo, transferencia bancaria, cheque, activo virtual, etc.)
- Monto para esta forma de pago
- Moneda

### Guardar

Haz clic en **Registrar Operación**. La operación se guarda y el motor de reglas de detección de alertas la evalúa de inmediato.

</Steps>

## Cálculos en UMA

La UMA (Unidad de Medida y Actualización) se actualiza anualmente el **1 de febrero** por el INEGI (p. ej. **$117.31 MXN/día** en 2026). Janovix automáticamente:

- Aplica el valor UMA correcto para la **fecha de operación** (no la fecha de registro)
- Calcula el equivalente en UMA para operaciones en múltiples monedas usando el tipo de cambio de la fecha de operación
- Compara el resultado con los umbrales del Art. 17 para determinar si la operación es reportable

<Callout type="info">
	Puedes consultar los valores UMA actuales e históricos en **Configuración →
	Cumplimiento**. Janovix mantiene una tabla completa de valores UMA anuales.
</Callout>

## Montos Acumulados

El Art. 17 de la LFPIORPI establece que las operaciones con el mismo cliente durante un **período móvil de 6 meses** que en conjunto superen el umbral de aviso deben ser reportadas. Janovix realiza un seguimiento de los montos acumulados por cliente y por actividad, y activará una alerta cuando el total acumulado cruce el umbral.

Para ver los montos acumulados de un cliente:

1. Abre la página de detalle del cliente
2. Navega a **Operaciones**
3. La tarjeta **Acumulado (6 meses)** muestra el total en ejecución por actividad

## Importación Masiva

Si tienes datos de transacciones existentes, usa la [Importación Masiva](/es/aml/import) para cargar operaciones mediante CSV en lugar de capturarlas una por una.

## Filtrar y Buscar Operaciones

Filtra la lista de operaciones por:

- Código de actividad
- Nombre o RFC del cliente
- Rango de monto
- Rango de fechas
- Moneda
- Reportable (por encima del umbral de aviso)

Todos los filtros persisten en la URL para facilitar el uso compartido.
