# Reportes

El módulo de **Reportes** permite a los oficiales de cumplimiento y directivos generar reportes de cumplimiento estructurados, dar seguimiento a métricas clave a lo largo del tiempo y exportar datos para auditorías o presentaciones a la dirección.

{/* IMAGE: public/images/aml/report-templates.png - Report template selection screen showing cards for each template type */}

## Plantillas de Reporte

Janovix ofrece siete plantillas de reporte:

| Plantilla              | Descripción                                                                                                                             |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `EXECUTIVE_SUMMARY`    | Resumen ejecutivo de cumplimiento: KPIs, conteo de alertas, estado de avisos. Diseñado para presentaciones a la dirección o al consejo. |
| `COMPLIANCE_STATUS`    | Estado detallado del cumplimiento: tasas de completitud KYC, avisos vencidos, alertas pendientes.                                       |
| `TRANSACTION_ANALYSIS` | Análisis profundo de operaciones: volumen por tipo de actividad, tendencias período a período, clientes principales.                    |
| `CLIENT_RISK_PROFILE`  | Desglose de clientes por nivel de riesgo, estado KYC y marcas en listas de vigilancia.                                                  |
| `ALERT_BREAKDOWN`      | Métricas de alertas: conteo por severidad, tasa de resolución, tiempo promedio de resolución.                                           |
| `PERIOD_COMPARISON`    | Comparación lado a lado de dos períodos (p. ej., T1 vs. T2).                                                                            |
| `CUSTOM`               | Crea tu propio reporte seleccionando las métricas y secciones que necesitas.                                                            |

## Generar un Reporte

1. Navega a **Cumplimiento → Reportes** y haz clic en **+ Nuevo Reporte**
2. Selecciona una plantilla
3. Establece el período de reporte (rango de fechas)
4. Previsualiza los datos usando la opción **Vista Previa**
5. Haz clic en **Generar** — el sistema compila el reporte
6. Una vez generado, descárgalo en PDF o visualízalo en pantalla

{/* IMAGE: public/images/aml/report-generated.png - Generated executive summary report showing charts, KPI tables, and narrative sections */}

## Ciclo de Vida del Reporte

Los reportes siguen un ciclo de vida simple de dos estados:

| Estado      | Descripción                                           |
| ----------- | ----------------------------------------------------- |
| `DRAFT`     | Reporte creado pero aún no compilado                  |
| `GENERATED` | Reporte compilado y listo para descarga/visualización |

<Callout type="info">
	Los reportes son **instantáneas en el tiempo**. Si actualizas datos de
	clientes o registras nuevas operaciones después de generar un reporte, el
	reporte no se actualizará automáticamente. Genera un nuevo reporte para
	reflejar los datos más recientes.
</Callout>

## Métricas Agregadas (API)

Para integraciones de tableros, Janovix proporciona endpoints de agregados precomputados:

- **Resumen Ejecutivo** (`GET /reports/aggregate/summary`) — Totales de KPIs para un período
- **Métricas de Alertas** (`GET /reports/aggregate/alerts`) — Estadísticas de alertas para un período

Consulta la [Guía de Integración API](/es/api/reports) para más detalles.

## Uso de Reportes en Auditorías

Cuando la SHCP realiza una visita de verificación (_visita de verificación_), deberás demostrar:

- Registros completos de identificación de clientes (KYC)
- Evidencia de operaciones registradas y avisos presentados
- Historial de detección y resolución de alertas
- Cumplimiento de la política de conservación de documentos

Genera un reporte `COMPLIANCE_STATUS` que cubra el período de auditoría para tener un resumen estructurado listo.
