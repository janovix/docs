# Avisos SAT

Los **Avisos SAT** son los reportes mensuales de cumplimiento que los sujetos obligados deben presentar ante la _Secretaría de Hacienda y Crédito Público_ (SHCP) a través del portal del SAT. Resumen todas las operaciones reportables del período.

{/* IMAGE: public/images/aml/notice-list.png - Notice list with month labels, status badges (DRAFT/GENERATED/SUBMITTED/ACKNOWLEDGED), and action buttons */}

## Ciclo de Vida del Aviso

{/* IMAGE: public/images/aml/notice-workflow.png - Diagram of the notice lifecycle: DRAFT → generate XML → GENERATED → submit to SAT → SUBMITTED → acknowledge → ACKNOWLEDGED */}

```
DRAFT → GENERATED → SUBMITTED → ACKNOWLEDGED
```

| Estado         | Descripción                                                    |
| -------------- | -------------------------------------------------------------- |
| `DRAFT`        | Aviso creado pero el XML del SAT aún no ha sido generado       |
| `GENERATED`    | Archivo XML del SAT generado y listo para su presentación      |
| `SUBMITTED`    | El oficial de cumplimiento ha enviado el XML al portal del SAT |
| `ACKNOWLEDGED` | El SAT respondió con un acuse de recibo                        |

## ¿Cuándo Debes Presentar?

Debes presentar un aviso por cada mes calendario en el que hayas registrado operaciones que alcanzaron o superaron el **umbral de aviso** definido para tu actividad en el Art. 17 de la LFPIORPI.

Adicionalmente:

- Siempre debe presentarse un aviso aunque el resultado sea de **cero operaciones reportables** (un "reporte en ceros"), dependiendo del tipo de actividad y el registro ante el SAT
- Los **avisos urgentes** (por actividad sospechosa) deben presentarse dentro de las **24 horas** y se crean a través del módulo de [Alertas](/es/aml/alerts)

<Callout type="info">
	El plazo estándar de presentación para los avisos mensuales es el **día 17 del
	mes calendario siguiente al período reportado**. Janovix muestra los días
	restantes hasta el vencimiento en la lista de Avisos.
</Callout>

## Crear un Aviso Mensual

<Steps>
### Navegar a Avisos
Ve a **Cumplimiento → Avisos SAT** en la barra lateral. La lista muestra todos los avisos de tu organización.

### Crear Nuevo Aviso

Haz clic en **+ Nuevo Aviso** y selecciona el período de reporte (año y mes). Janovix mostrará:

- Una vista previa de todas las operaciones de ese mes que califican para el aviso
- Un resumen: número de operaciones, valor total, desglose por actividad

### Revisar la Vista Previa

{/* IMAGE: public/images/aml/notice-generate.png - Notice generation screen showing XML preview, operation count, total amount, and per-activity breakdown */}

Antes de generar el XML, revisa el resumen del aviso:

- Verifica que el número de operaciones y los montos coincidan con tus registros
- Asegúrate de que todos los clientes estén correctamente identificados (KYC completo)
- Confirma que no haya operaciones en borrador que deberían incluirse

### Generar XML SAT

Haz clic en **Generar XML**. El sistema produce un archivo XML válido del SAT conforme al _Formato de Aviso en materia de Prevención e Identificación de Operaciones con Recursos de Procedencia Ilícita_.

El estado del aviso cambia a `GENERATED`.

### Revisar y Descargar el XML

Expande la tarjeta del aviso para ver la vista previa del XML. Descarga el archivo XML a tu computadora.

### Presentar en el Portal SAT

Inicia sesión en el portal de cumplimiento del SAT y sube el archivo XML. Ingresa el **número de folio** que el SAT proporciona al recibir el archivo exitosamente.

### Marcar como Enviado

Regresa a Janovix, abre el aviso y haz clic en **Marcar como Enviado**. Ingresa el número de folio del SAT. El estado del aviso cambia a `SUBMITTED`.

### Acusar Recibo

Cuando recibas el acuse de recibo del SAT (_acuse de recibo_), haz clic en **Acusar Recibo** y opcionalmente adjunta el documento del acuse. El estado cambia a `ACKNOWLEDGED`.

</Steps>

## Contenido del Aviso

El XML del SAT generado incluye:

| Sección                         | Contenido                                                                                                                    |
| ------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| **Encabezado**                  | RFC de tu organización, código de actividad (_clave de actividad_), período                                                  |
| **Sujeto Obligado**             | Tu RFC, razón social, domicilio fiscal                                                                                       |
| **Operaciones**                 | Cada operación calificada con: datos del cliente, tipo de operación, monto, formas de pago, campos específicos por actividad |
| **Controladores Beneficiarios** | Para cada cliente persona moral: datos del controlador beneficiario                                                          |
| **Folio**                       | Asignado por el SAT al momento de la aceptación                                                                              |

<Callout type="warning">
	El formato XML del SAT debe coincidir exactamente con la especificación
	publicada por la SHCP. Janovix mantiene sus plantillas XML actualizadas con
	los cambios de formato del SAT. Si encuentras un rechazo, verifica en
	**Configuración → Cumplimiento** que el RFC y el código de actividad de tu
	organización estén correctamente configurados.
</Callout>

## Vista Previa del Aviso

Antes de generar el XML, utiliza la función de **Vista Previa** (disponible a través de la API en `GET /notices/preview`) para ver qué operaciones y clientes se incluirán con base en los datos actuales. Esto ayuda a detectar problemas de calidad de datos antes de generar el XML formal.

## Eliminar un aviso

Desde la **lista de avisos** o el **detalle**, puedes **eliminar** avisos en estado **`DRAFT`** o **`GENERATED`** (antes de enviarlos al SAT). Eso elimina el aviso para que corrijas datos y **crees un aviso nuevo** para el mismo mes.

Cuando el aviso pasa a **`SUBMITTED`** o estados posteriores, ya no se elimina desde la interfaz — sigue los flujos hacia el SAT del producto (descarga XML, acuse, rechazo, etc.).

Si necesitas corregir datos antes del envío:

1. Elimina el aviso `DRAFT` o `GENERATED` (si aún está permitido)
2. Corrige operaciones o KYC del cliente
3. Crea un nuevo aviso para el mismo período

## Meses Disponibles

El sistema muestra únicamente los meses para los cuales existe al menos una operación reportable. Usa **+ Nuevo Aviso** → **Meses Disponibles** para ver la lista completa de períodos disponibles para tu organización.
