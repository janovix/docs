# Alertas

Las **Alertas** son notificaciones generadas cuando el sistema detecta actividad potencialmente sospechosa o cuando una operación supera el umbral de reporte definido en el Art. 17. Los oficiales de cumplimiento revisan, investigan y resuelven cada alerta, o la escalan a un aviso ante el SAT.

{/* IMAGE: public/images/aml/alert-list.png - Alert list with severity color badges (CRITICAL/HIGH/MEDIUM/LOW), status chips, and client names */}

## Ciclo de Vida de una Alerta

```
DETECTED → FILE_GENERATED → SUBMITTED
              ↕
           OVERDUE
              ↕
           CANCELLED
```

| Estado           | Descripción                                                            |
| ---------------- | ---------------------------------------------------------------------- |
| `DETECTED`       | Alerta generada; pendiente de revisión por el oficial de cumplimiento  |
| `FILE_GENERATED` | Se ha generado el archivo XML del SAT para esta alerta                 |
| `SUBMITTED`      | La alerta ha sido reportada ante el SAT                                |
| `OVERDUE`        | El plazo de envío venció sin haber realizado la presentación           |
| `CANCELLED`      | La alerta fue investigada y se determinó que no requiere ser reportada |

## Niveles de Severidad de Alerta

| Severidad  | Color    | Detonante Típico                                                           |
| ---------- | -------- | -------------------------------------------------------------------------- |
| `CRITICAL` | Rojo     | Cliente sancionado (coincidencia OFAC/UNSC), reporte inmediato ante el SAT |
| `HIGH`     | Naranja  | Operación significativamente por encima del umbral, PEP involucrado        |
| `MEDIUM`   | Amarillo | Operación en o cerca del umbral, primera ocurrencia                        |
| `LOW`      | Azul     | Informativo — patrón detectado, se recomienda monitoreo                    |

## Cómo se Generan las Alertas

Las alertas pueden generarse de dos formas:

### Automática (Basada en Reglas)

El motor de reglas de alerta evalúa cada operación en el momento en que se registra. Las reglas pueden configurarse para activarse con base en:

- Monto de la operación vs. umbrales del Art. 17
- Totales acumulados en 6 meses que superan el umbral de aviso
- Marcas de lista de vigilancia del cliente (PEP, OFAC, UNSC, SAT 69-B)
- Patrones específicos por actividad (p. ej., operaciones fraccionadas)
- Reglas de negocio personalizadas

{/* IMAGE: public/images/aml/alert-rules.png - Alert rules configuration screen showing active rules, their severity, and activity codes they apply to */}

### Manual

Los oficiales de cumplimiento pueden crear alertas manuales para situaciones no cubiertas por las reglas automatizadas:

1. Navega a **Alertas** → **+ Nueva Alerta**
2. Vincula la alerta a un cliente y/o una operación
3. Establece la severidad y describe el motivo
4. La alerta entra al estado `DETECTED`

## Revisión de una Alerta

{/* IMAGE: public/images/aml/alert-detail.png - Alert detail page showing client info, operation details, timeline of status changes, and action buttons */}

<Steps>
### Abrir la Alerta
Haz clic en una alerta de la lista para abrir su página de detalle. Verás:
- La(s) operación(es) detonadora(s)
- Información del cliente, incluyendo resultados del escrutinio en listas de vigilancia
- Metadatos de la alerta (severidad, fecha de creación, fecha límite)

### Investigar

Revisa el historial de transacciones del cliente, identifica la operación que activó la regla y evalúa si constituye actividad sospechosa.

### Tomar Acción

**Opción A — Generar Archivo SAT y Enviar**
Si la alerta requiere ser reportada:

- Haz clic en **Generar Archivo SAT** — el sistema produce un XML del SAT conforme a la normativa
- Revisa el archivo XML
- Descárgalo y envíalo a través del portal del SAT; luego haz clic en **Marcar como Enviado** en Janovix

**Opción B — Cancelar la Alerta**
Si la investigación determina que la actividad es legítima:

- Haz clic en **Cancelar Alerta**
- Proporciona una breve justificación (queda registrada en la bitácora de auditoría)

</Steps>

<Callout type="warning">
	**Alertas urgentes (severidad CRITICAL):** El Art. 18 requiere presentar un
	aviso dentro de las **24 horas** siguientes a la detección de actividad
	sospechosa. Janovix muestra un contador regresivo en las alertas críticas con
	el tiempo restante antes del vencimiento.
</Callout>

## Configuración de Reglas de Alerta

Navega a **Alertas → Reglas** para gestionar tu conjunto de reglas. Cada regla tiene:

| Campo                   | Descripción                                                                                |
| ----------------------- | ------------------------------------------------------------------------------------------ |
| **Tipo de Regla**       | La lógica de detección (umbral, acumulación, coincidencia en lista, etc.)                  |
| **Código de Actividad** | A qué actividad aplica esta regla (o a todas las actividades)                              |
| **Severidad**           | La severidad asignada cuando se activa la regla                                            |
| **Activa**              | Habilita/deshabilita la regla sin eliminarla                                               |
| **Solo Manual**         | La regla se activa pero crea una alerta únicamente cuando un usuario la detona manualmente |
| **Configuración**       | Parámetros clave-valor específicos de la regla (p. ej., multiplicador de umbral)           |

<Callout type="info">
	El conjunto de reglas predeterminado cubre todos los umbrales de aviso del
	Art. 17. Puedes agregar reglas personalizadas además de las predeterminadas —
	por ejemplo, para señalar clientes con más de 5 operaciones en un solo mes sin
	importar los montos individuales.
</Callout>

## Idempotencia

Cada alerta tiene un campo `idempotencyKey`. Cuando una operación activa una regla, el sistema verifica si ya se generó una alerta idéntica para la misma combinación operación+regla. Esto evita la acumulación de alertas duplicadas cuando se actualiza una operación.
