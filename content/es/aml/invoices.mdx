# Facturas (CFDI)

El módulo de **Facturas** te permite importar, gestionar y vincular facturas electrónicas CFDI v4.0 (_Comprobante Fiscal Digital por Internet_) a tus operaciones. Esto es especialmente útil para empresas en las que las transacciones generan documentos CFDI (p. ej., venta de vehículos, cierre de operaciones inmobiliarias, servicios profesionales).

{/* IMAGE: public/images/aml/invoice-list.png - Invoice list showing CFDI UUID, issuer RFC, receiver RFC, total amounts, and date */}

## ¿Qué es un CFDI?

Un CFDI (Comprobante Fiscal Digital por Internet) es el formato estandarizado de factura electrónica en México, obligatorio por el SAT para efectos fiscales. La versión CFDI v4.0 es la versión vigente.

Janovix admite:

- Captura manual de facturas
- **Parseo de XML** — pega o sube un archivo XML de CFDI y Janovix extrae todos los campos automáticamente

## Importar un CFDI mediante XML

{/* IMAGE: public/images/aml/invoice-parse-xml.png - CFDI XML upload/paste interface with extracted field preview */}

1. Navega a **Transacciones → Facturas** y haz clic en **+ Importar CFDI**
2. Elige **Parsear XML**
3. Pega o sube el archivo XML del CFDI
4. Janovix extrae y llena automáticamente:
   - Emisor: RFC, nombre, régimen fiscal
   - Receptor: RFC, nombre, uso del CFDI
   - Datos financieros: subtotal, impuestos, total
   - Información de pago: método de pago, forma de pago
   - TFD (Timbre Fiscal Digital): UUID, fecha de certificación, certificado SAT
5. Revisa los datos extraídos y haz clic en **Guardar**

<Callout type="info">
	El UUID (Folio Fiscal) se extrae del nodo TFD del XML del CFDI. Janovix aplica
	unicidad por UUID dentro de tu organización para evitar importaciones
	duplicadas.
</Callout>

## Crear una operación desde un CFDI (flujo de revisión)

Tras analizar y guardar la factura, abre el detalle y usa **Crear operación desde CFDI** (ruta `/{orgSlug}/invoices/{id}/create-operation`). Se abre la **revisión del CFDI** donde:

1. Confirmas emisor/receptor, totales, impuestos y UUID
2. Mapeas el CFDI al **cliente** correcto y a los campos de **actividad vulnerable**
3. Envías para generar una **[operación](/es/aml/operations)** enlazada con contexto fiscal

Es la vía recomendada cuando el hecho económico del CFDI debe quedar como operación AML.

## Vincular a una operación ya existente

Si la operación ya se capturó manualmente, abre la factura y usa **Vincular a Operación** para adjuntarla de forma retroactiva y conservar la trazabilidad.

## Campos del CFDI Almacenados

| Sección        | Campos                                                                         |
| -------------- | ------------------------------------------------------------------------------ |
| **Encabezado** | UUID, fecha/hora, versión (4.0), moneda, tipo de cambio                        |
| **Emisor**     | RFC, nombre, régimen fiscal                                                    |
| **Receptor**   | RFC, nombre, código postal, uso del CFDI                                       |
| **Totales**    | Subtotal, descuentos, impuestos trasladados, impuestos retenidos, total        |
| **Pago**       | Método de pago, forma de pago                                                  |
| **TFD**        | UUID, RFC del PAC, fecha de certificación, número de serie del certificado SAT |

## Importación Masiva de CFDI

Para escenarios de alto volumen, utiliza la API interna (`POST /internal/invoices/parse-xml`) para automatizar la ingesta de CFDI desde tu sistema de facturación. Consulta la [Guía de Integración API](/es/api/index) para más detalles.
