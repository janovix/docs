# Importación Masiva

El módulo de **Importación Masiva** te permite migrar datos existentes a Janovix o cargar grandes lotes de clientes y operaciones sin necesidad de capturar los registros uno por uno.

{/* IMAGE: public/images/aml/import-wizard.png - Import wizard showing entity type selector (CLIENT/OPERATION), file upload area, and template download button */}

## Tipos de Entidad Compatibles

| Entidad     | Descripción                                       |
| ----------- | ------------------------------------------------- |
| `CLIENT`    | Personas físicas, personas morales y fideicomisos |
| `OPERATION` | Operaciones para cualquier código de actividad    |

## Obtener la Plantilla CSV

Siempre parte de la plantilla CSV oficial de Janovix para asegurarte de utilizar los encabezados de columna y el formato de datos correctos. Las plantillas están disponibles sin autenticación:

- **Plantilla de clientes:** `GET /api/v1/imports/templates/CLIENT`
- **Plantilla de operaciones (específica por actividad):** `GET /api/v1/imports/templates/OPERATION/{activityCode}`

Cada plantilla incluye:

- Columnas requeridas y opcionales
- Valores aceptados para campos de tipo enumerado
- Notas de formato en una fila de encabezado

<Callout type="warning">
	No modifiques los encabezados de columna en la plantilla CSV. El procesador de
	importación realiza una coincidencia estricta de encabezados. Las columnas
	adicionales o con nombres cambiados provocarán que la importación falle.
</Callout>

## Ejecutar una Importación

{/* VIDEO: 2 min walkthrough showing a bulk client import: download template, fill data, upload, review progress, and handle errors */}

<Steps>
### Preparar el Archivo CSV
Abre la plantilla descargada en Excel o Google Sheets y completa tus datos:
- Una fila por cliente u operación
- Sigue los tipos de datos especificados en las notas de la plantilla
- El RFC debe tener la longitud correcta según el tipo de entidad
- Las fechas deben estar en formato `YYYY-MM-DD`

### Subir el Archivo

Navega a **Gestión de Datos → Importar** y haz clic en **+ Nueva Importación**:

1. Selecciona el tipo de entidad (CLIENT u OPERATION)
2. Para operaciones, selecciona el código de actividad
3. Haz clic en **Elegir Archivo** y selecciona tu CSV

### Monitorear el Progreso

{/* IMAGE: public/images/aml/import-progress.png - Import progress screen with a progress bar, phase labels (VALIDATING/PROCESSING), and real-time row counter */}

La importación se ejecuta de forma asíncrona. El progreso se transmite en tiempo real mediante Server-Sent Events (SSE):

| Fase         | Descripción                                        |
| ------------ | -------------------------------------------------- |
| `PENDING`    | Archivo recibido, en espera de inicio              |
| `VALIDATING` | Verificando el formato de datos en todas las filas |
| `PROCESSING` | Creando registros en la base de datos              |
| `COMPLETED`  | Todas las filas procesadas correctamente           |
| `FAILED`     | Importación interrumpida por un error crítico      |

### Revisar Resultados

{/* IMAGE: public/images/aml/import-results.png - Import results table showing row number, status (SUCCESS/ERROR), and error message for failed rows */}

Una vez que la importación termine, abre la vista de **Resultados** para ver:

- Total de filas procesadas
- Importaciones exitosas
- Filas con error y mensajes de error específicos por fila (p. ej., "Formato de RFC inválido", "Cliente no encontrado")

Descarga el reporte de resultados para corregir errores y reimportar únicamente las filas fallidas.

</Steps>

## Límites de Importación

| Límite                      | Valor                                 |
| --------------------------- | ------------------------------------- |
| Máximo de filas por archivo | 100 filas por lote                    |
| Tamaño máximo de archivo    | Determinado por tu plan               |
| Importaciones simultáneas   | 1 importación activa por organización |

<Callout type="info">
	Para conjuntos de datos mayores a 100 filas, divide tu CSV en varios archivos
	y súbelos de forma secuencial. Espera a que cada importación termine antes de
	iniciar la siguiente.
</Callout>

## Consejos para Importaciones Limpias

1. **Valida los RFC** antes de subir el archivo — usa un validador local de RFC o la herramienta en línea del SAT
2. **Registra primero a los clientes** — si vas a importar operaciones, asegúrate de que todos los RFC de clientes ya estén en el sistema o en el mismo lote
3. **Usa la vista previa** — la importación valida todas las filas antes de procesarlas, por lo que una ejecución de validación detectará la mayoría de los errores sin crear ningún registro
4. **Verifica duplicados** — el importador rechazará clientes con RFC duplicados dentro de la misma organización
