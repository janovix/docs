# Manual de Configuración

La aplicación de **Configuración** es tu centro de control para gestionar tu cuenta de Janovix, organización, miembros del equipo, configuración de cumplimiento y facturación.

Accede en **[auth.janovix.com/settings](https://auth.janovix.com/settings)**, o desde cualquier aplicación de Janovix haciendo clic en tu avatar en la esquina superior derecha y seleccionando **Configuración**.

## Navegación

La barra lateral de Configuración tiene dos secciones:

### Configuración de Usuario

Se aplica a tu cuenta personal en todas las organizaciones:

- **Personal** — Perfil, avatar, zona horaria, tema, idioma
- **Facturación** — Tu plan de suscripción, métricas de uso y pago

### Configuración de Organización

Se aplica a la organización actualmente seleccionada:

- **Organización** — Nombre, logo, zona horaria, formato de hora
- **Cumplimiento AML** — Código de actividad, RFC, configuración del autoservicio KYC
- **Equipo** — Miembros, roles e invitaciones pendientes
- **Llaves de API** — Crea y administra llaves de API para acceso programático
