# Configuración Personal

La configuración personal se aplica a tu cuenta de usuario en **todas las organizaciones** a las que perteneces.

{/* IMAGE: public/images/settings/settings-personal.png - Personal settings page showing avatar upload, name fields, email, timezone selector, theme toggle, and language selector */}

## Perfil

| Campo                  | Descripción                                                                                          |
| ---------------------- | ---------------------------------------------------------------------------------------------------- |
| **Avatar**             | Foto de perfil. Haz clic en el círculo del avatar para subir una nueva imagen (JPEG/PNG, máx. 5 MB). |
| **Nombre Visible**     | Tu nombre tal como lo ven otros miembros del equipo y como aparece en los registros de auditoría.    |
| **Correo Electrónico** | Tu correo de inicio de sesión. Contacta a soporte para cambiar tu dirección de correo.               |

## Preferencias

| Configuración        | Opciones                                                    | Predeterminado |
| -------------------- | ----------------------------------------------------------- | -------------- |
| **Tema**             | Claro / Oscuro / Sistema                                    | Sistema        |
| **Idioma**           | English / Español / Português                               | English        |
| **Zona Horaria**     | Cualquier zona horaria IANA (p. ej., `America/Mexico_City`) | `UTC`          |
| **Formato de Hora**  | 12 horas / 24 horas                                         | 12 horas       |
| **Formato de fecha** | Patrones según configuración regional                       | Predeterminado |

<Callout type="info">
	La **Zona Horaria** afecta cómo se muestran las fechas y horas en toda la
	aplicación — reportes, marcas de tiempo de operaciones y fechas límite de
	avisos. Configúrala con tu zona horaria local para evitar confusiones.
</Callout>

## Notificaciones

Configura el **sonido** de notificaciones en la aplicación:

- Activar o desactivar el sonido
- Elegir un **tipo de sonido** y usar **Vista previa** antes de guardar

## Passkeys (WebAuthn)

Para un inicio de sesión más fuerte sin SMS, añade **passkeys** (clave de plataforma o de seguridad):

- **Añadir** desde un navegador compatible (Face ID, Touch ID, Windows Hello, llave física)
- **Renombrar** para recordar el dispositivo
- **Eliminar** si pierdes un equipo

Son opcionales pero recomendables tras el OTP por correo.

## Interfaz

Janovix recuerda si prefieres la barra lateral **expandida** o **contraída**. La preferencia se **persiste en el servidor con debounce** para conservarse entre dispositivos y sesiones.

## Seguridad

Para cerrar sesión en todos los dispositivos, haz clic en **Cerrar Sesión en Todos los Dispositivos** en la parte inferior de la página de Configuración Personal. Esto invalida todas las sesiones activas de tu cuenta.
